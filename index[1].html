1. ¿Cómo funciona la web?

Un navegador (cliente) pide páginas a un servidor mediante el protocolo HTTP. El servidor responde con archivos HTML, CSS y JavaScript.

2. HTML: la estructura

HTML usa etiquetas para describir el contenido: <h1> títulos, <p> párrafos, <img> imágenes y <a href="..."> hipervínculos. Las etiquetas se anidan formando un árbol.

📚 MDN · Aprende HTML · W3Schools · HTML

🎬 Curso de HTML5 y CSS3 en español. ¿No carga? Ábrelo en YouTube.

3. CSS: el diseño

CSS controla colores, tipografías y distribución. Ejemplo: h1 { color: tomato; }. Cada elemento es una caja con contenido, relleno (padding), borde y margen.

📚 MDN · Aprende CSS · Guía de Flexbox

🎬 Curso de CSS. ¿No carga? Ábrelo en YouTube.

4. JavaScript: la interacción

JavaScript (que no es lo mismo que Java) permite reaccionar a clics, validar formularios y modificar la página. Para mostrar mensajes de prueba se usa console.log("Hola").

📚 MDN · Aprende JavaScript · javascript.info

🎬 Tutorial de JavaScript. ¿No carga? Ábrelo en YouTube.

5. Publicar en un hosting

El hosting es el servicio que guarda tus archivos y los entrega a quien visite tu dirección web (dominio). Hay opciones gratuitas como GitHub Pages y Netlify.
